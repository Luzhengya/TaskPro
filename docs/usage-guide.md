# TaskMaster AI 使用说明

TaskMaster AI 是面向个人和小团队的任务管理系统。系统以“案件/项目”和“子任务”为核心，支持任务跟踪、定例作业自动生成、日报、周报、模板复用、Excel 导入、履历归档和基础设置。

## 1. 登录与数据保存

### 1.1 邮箱登录

进入系统后，可以使用邮箱和密码登录。新用户需要通过邮箱验证码完成注册。

### 1.2 访客模式

如果只想试用系统，可以进入访客模式。访客模式的数据保存在当前浏览器本地存储中，不会同步到其他设备。

### 1.3 密码重置

登录页提供密码重置入口。按页面提示输入邮箱、获取验证码，并设置新密码。

## 2. 主菜单说明

系统左侧或底部导航包含以下页面：

| 菜单 | 用途 |
| --- | --- |
| 案件一覧 | 查看、创建、搜索和管理案件/项目 |
| テンプレ | 管理可复用的任务模板 |
| 履歴 | 查看已归档的案件 |
| インポート | 从 Excel 导入案件和任务 |
| 日報 | 自动抽取、编辑、提交和下载日报 |
| 設定 | 配置 UI、快捷筛选和危险操作 |

## 3. 案件一覧

### 3.1 创建普通案件

1. 点击“新規プロジェクト”。
2. 选择“通常案件”。
3. 输入项目名。
4. 设置项目期日。
5. 可选：选择一个任务模板。
6. 点击“作成”。

如果选择了任务模板，系统会按模板内容自动生成子任务。

### 3.2 创建定例作业集合

定例作业集合用于管理会议、每日任务、每周任务、每月任务等周期性工作。

1. 点击“新規プロジェクト”。
2. 选择“繰り返し作業”。
3. 输入繰り返し作业集合名，例如“会議”或“繰り返し作業”。
4. 点击“作成”。

定例作业集合本身不要求项目期日。进入该集合后，可以创建定例テンプレート。

### 3.3 案件状态筛选

案件一覧支持按状态查看项目：

| 筛选 | 含义 |
| --- | --- |
| すべて | 所有显示中的案件 |
| 遅延あり | 存在延期或期限迟延的案件 |
| 着手遅れ | 存在开始延迟的案件 |
| 期日間近 | 期日在设定营业日范围内临近 |
| 開始間近 | 开始日在设定营业日范围内临近 |
| 進行中 | 存在进行中的任务 |
| 完了 | 全部任务已完成 |

“期日間近”和“開始間近”的判定天数可在“設定”中调整。

### 3.4 搜索与详细筛选

案件一覧上方提供任务搜索：

- 可以按任务名、备注关键词搜索。
- 点击“絞り込み”可设置详细条件。
- 设置中的“クイックフィルタ”会显示为快捷筛选按钮。

搜索结果以子任务列表形式展示。点击结果可跳转到对应案件的子任务管理页面。

### 3.5 显示模式

项目页面支持以下视图：

- グリッド：卡片视图。
- テーブル：表格视图。
- 週報：周报视图。

可在“設定 > UI設定 > プロジェクト画面の表示ビュー”中控制哪些视图显示。

### 3.6 归档案件

在案件卡片或列表中点击“非表示（履歴へ）”，可以把案件移动到“履歴”。归档后，案件不会出现在普通列表和搜索结果中，但仍可在履歴中查看和恢复。

## 4. 子任务管理

点击案件后进入子任务管理页面。

### 4.1 子任务字段

子任务主要字段如下：

| 字段 | 说明 |
| --- | --- |
| 日報 | 是否手动加入日报 |
| システム | 系统/分类/对象 |
| タスク名 | 任务名称 |
| ステータス | 当前状态 |
| 開始日 | 计划开始日期 |
| 期日 | 任务期日 |
| 期限 | 最终期限 |
| 予定 | 计划工时 |
| 実績 | 实际工时 |
| 優先度 | 优先级 A/B/C |
| 備考 | 备注 |

### 4.2 添加任务

点击“タスク追加”添加一行子任务。新增任务默认状态为“未着手”，实际工时默认为未输入。

### 4.3 编辑任务

子任务表格中的大多数字段可以直接编辑。修改后系统会保存到数据库或本地访客数据。

### 4.4 拖拽排序

子任务表支持拖拽排序。排序结果会保存，之后再次打开仍按该顺序显示。

### 4.5 删除任务

点击任务行的删除按钮，并在确认弹窗中确认，即可删除该子任务。

### 4.6 延期与影响

当任务出现延迟时，可以填写延迟原因和影响天数。系统会保留被移动前的原期日/期限，并在界面中以对比形式展示。

## 5. 定例テンプレート

定例テンプレート只在“繰り返し作業”类型的案件中使用。

### 5.1 创建定例模板

1. 进入一个定例作业集合。
2. 点击“定例テンプレート追加”。
3. 输入任务名，例如“朝会”“日報作成”“週次会議”。
4. 设置系统/分类、计划工时、优先级。
5. 选择周期：
   - 毎日：每天生成。
   - 毎週：选择星期几生成。
   - 毎月：选择每月几号生成。
6. 点击“保存”。

### 5.2 定例任务如何生成

定例模板本身不会直接显示在普通子任务表中。用户打开“日報”页面时，系统会检查今天是否有符合规则的定例模板。如果有，就自动生成当天的实际任务。

生成的实际任务会带有当天日期：

- 日報日期 = 当天
- 开始日 = 当天
- 期日 = 当天
- 期限 = 当天

例如 2026/06/08 是星期一，则以下模板会生成实际任务：

- 毎日
- 毎週 月

以下模板不会在当天生成：

- 毎週 火
- 毎週 水
- 毎週 金
- 毎月 1・26日

### 5.3 定例任务与日报、周报的关系

- 日报页面负责触发定例模板的实际任务生成。
- 定例模板不会直接进入日报。
- 生成后的实际任务会作为普通任务进入日报和周报。
- 周报不负责生成定例任务，只展示已经存在的实际任务。

### 5.4 重复生成说明

系统已加入“同一模板 + 同一天”的生成保护。正常情况下，同一个定例模板在同一天只会生成一次实际任务。

如果此前已经产生重复任务，需要手动删除多余的重复行。删除重复实际任务不会删除定例模板。

## 6. 日報

日报页面用于生成、编辑、提交和下载每日工作报告。

### 6.1 自动进入日报的任务

以下任务会出现在日报中：

- 手动勾选了“日報”的任务。
- 定例作业集合下，开始日等于今天的任务。
- 打开日报当天自动生成的定例任务。

定例模板本身不会直接显示在日报中。

### 6.2 自动抽出

点击“自動抽出”后，系统会重新判断今天可能需要报告的任务，并勾选到日报中。

注意：

- 自动抽出会重置当天已有的日报勾选状态。
- 如果有任务被手动加入日报，执行自动抽出后可能需要重新确认。
- 历史日期不能执行自动抽出。

### 6.3 编辑日报

日报中可以编辑：

- 任务的实际工时。
- 任务备注。
- 日报备注。
- 系统生成或整理出的摘要。

### 6.4 提交日报

点击“日報を提出”后，系统会保存当天日报快照。再次提交会更新已保存的快照。

保存后的日报快照可用于历史查看。

### 6.5 下载日报

点击下载按钮可以下载文本格式日报。

### 6.6 查看历史日报

在日报页面上方选择过去日期，可以查看对应日期的日报快照。历史日报为只读模式。

### 6.7 清除日报

点击清除按钮：

- 今天：清除当天日报勾选和保存内容。
- 历史日期：删除该日期的日报快照。

## 7. 週報

週報是案件一覧中的一种显示模式。

### 7.1 打开周报视图

在案件一覧页面切换到“週報モード”。如果看不到周报视图，可到“設定 > UI設定”中启用“週報”。

### 7.2 周报显示内容

周报展示当前项目下的实际子任务，并按周进行展示和统计。

注意：

- 定例模板不会进入周报。
- 由定例模板生成的实际任务会进入周报。
- 已归档案件默认不在周报中显示。

### 7.3 优先级统计

周报顶部会按优先级统计任务数量：

- A：高
- B：中
- C：低

## 8. テンプレ

テンプレ页面用于维护普通项目可复用的任务模板。

### 8.1 创建模板

1. 进入“テンプレ”。
2. 创建新的模板。
3. 在模板下添加任务项。
4. 设置任务名、工时、顺序等内容。

### 8.2 使用模板

创建普通案件时，在“テンプレ（任意）”下拉框中选择模板。系统会把模板中的任务项生成为该案件的子任务。

### 8.3 删除模板

删除模板会同时删除模板下的任务项，但不会影响已经通过该模板生成出的真实任务。

## 9. インポート

インポート页面用于从 Excel 批量导入案件和子任务。

### 9.1 支持格式

仅支持 `.xlsx` 文件。

### 9.2 导入方式

1. 进入“インポート”。
2. 点击上传区域，或拖拽 Excel 文件到上传区域。
3. 系统读取文件并创建案件和子任务。

### 9.3 导入模板

点击“インポートテンプレートをダウンロード（Excel）”可下载系统提供的模板文件。

### 9.4 数据规则

- 第 1 行为表头。
- 第 2 行起为数据。
- 如果存在名为 `import` 的工作表，优先读取该工作表。
- 系统按“案件”分组创建父任务。
- 每一行数据会生成一条子任务。

## 10. 履歴

履歴页面用于查看已归档的案件。

### 10.1 查看归档案件

进入“履歴”后，可以看到被移动到履历的案件。

### 10.2 恢复案件

在履歴中可将案件恢复为显示状态。恢复后，案件会重新出现在案件一覧。

### 10.3 完全删除

履歴中提供完全删除操作。完全删除后，案件及相关任务会被删除，操作不可撤销。

## 11. 設定

### 11.1 AI 设置

AI 设置区域显示系统使用的模型。当前用于任务摘要和分析。

### 11.2 UI 设置

可以设置：

- “期日間近・開始間近”的判定营业日范围。
- 案件页面可用的显示视图：グリッド、テーブル、週報。

### 11.3 快捷筛选

“クイックフィルタ”用于管理案件一覧上方的快捷筛选按钮。

可创建、编辑、删除快捷筛选。常见用途：

- 今日が期日
- 優先A・未完
- 遅延タスク
- 開始日が近いタスク

### 11.4 通知设置

通知设置当前为准备中状态，界面暂不可操作。

### 11.5 危险操作

“全タスク削除”会删除当前显示中的案件及其子任务。

注意：

- 该操作不会删除履歴中的案件。
- 不会删除模板。
- 不会删除日报快照。
- 操作不可撤销，请谨慎使用。

## 12. 常见使用流程

### 12.1 新建普通项目并跟踪任务

1. 在案件一覧点击“新規プロジェクト”。
2. 选择“通常案件”。
3. 输入项目名和期日。
4. 可选：选择模板。
5. 进入项目，补充或编辑子任务。
6. 每天在相关任务上勾选“日報”，或使用日报自动抽出。
7. 在日報页面提交日报。
8. 在週報模式查看周度进展。

### 12.2 管理每日/每周/每月定例任务

1. 在案件一覧创建“繰り返し作業”类型项目。
2. 进入该项目。
3. 点击“定例テンプレート追加”。
4. 设置周期和任务信息。
5. 每天打开日報页面时，系统会自动生成当天符合条件的定例任务。
6. 生成后的实际任务可在日报、周报和子任务表中查看。

### 12.3 批量导入项目

1. 进入“インポート”。
2. 下载导入模板。
3. 按模板填写 Excel。
4. 上传 `.xlsx` 文件。
5. 导入完成后，在案件一覧检查项目和子任务。

## 13. 注意事项

- 访客模式数据只保存在当前浏览器。
- 定例模板不是实际任务，只有在符合日期规则时才会生成实际任务。
- 周报只展示实际任务，不展示定例模板。
- 已归档案件不会出现在普通搜索和周报中。
- 自动抽出日报会重置当天日报勾选，请在执行后确认任务列表。
- 删除操作通常不可撤销，尤其是完全删除和全任务删除。
